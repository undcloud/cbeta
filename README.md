# CBETA

CBETA 經典全文搜尋 Flutter App。

一般搜尋會同時查詢 CBETA 的 `/stable/search/all_in_one` 全文 API 與 `/stable/search/toc` 經目 API；任一先返回便先顯示，經目命中會優先排序。經目結果預設顯示前五部，更多結果可點擊「顯示更多」展開；全文搜尋結果則在捲動至列表底部時繼續載入。簡體輸入會先轉為繁體，再以轉換後的查詢呼叫 API。全文搜尋採用網站相同的每頁 20 筆、`around=30` 片段與 facet 參數，並保留網站回傳的 KWIC 分組。符合 CBETA 行號或引文格式的輸入會直接執行 Goto 並開啟對應經文，不會執行關鍵字搜尋。

點選搜尋命中時，閱讀頁會像 CBETA 網站一樣載入該作品的完整卷文，並自動定位到命中的行號。首次開啟的經卷會下載並保存在裝置上；之後開啟已保存的經卷會直接讀取離線資料，不會重新連線下載。

閱讀頁的上一卷／下一卷按鈕位於卷文末尾；從搜尋結果開啟經文時，搜尋命中導航固定於頁面底部。切換同一經卷內的命中會沿用已載入卷文，不重新發送請求；切換到尚未載入的其他卷時才會請求該卷，或使用已快取的卷文。導航也可返回搜尋結果列表。

閱讀正文預設比照 CBETA 網頁：宣紙背景、紙色工具列與搜尋導航、19px 明體、1.9 行高、680px 居中閱讀欄。詩偈保留成對句格並置中；校勘標記可點開對應注釋，CBETA 修訂標記亦可顯示修訂內容。行首設定會在正文行旁顯示 CBETA 行碼。工具列的「介面設定」可調整字級、行高、字型、背景、勘校標記及行首顯示；設定會儲存在裝置上。關於我們頁面目前留白。

閱讀時會先載入該卷完整 HTML，供定位、行碼與校勘注使用；首次載入時間主要取決於卷文下載與 HTML 解析。設定面板中的「更新離線經文」會逐卷檢查本機保存內容，並依 CBETA API 的內容識別碼更新有變動的經卷。命中定位只排版命中位置之前的文字，不再額外測量整卷全文。

閱讀頁工具列支援當卷搜尋（含上一筆／下一筆）。經文中的 CBETA 插圖會依閱讀欄寬度顯示；CBETA `bip-table` 及標準 HTML 表格會保留欄列排版，表格文字仍可供當卷搜尋。搜尋依原始經文查找，即使命中詞被勘校標記分隔仍會分段高亮，並將命中位置置於可視區域中央（靠近卷首或卷尾時受可捲動範圍限制）。首頁全文搜尋與閱讀頁全文搜尋共用記憶體快取；首頁首次搜尋成功後就會快取結果，從搜尋命中進入閱讀頁再開啟全文搜尋時可立即顯示同一查詢結果，不需重送請求。載入更多結果後也會更新快取。

經文選擇器提供部類、冊別、作譯者、年代、經目查詢與 Goto 查詢六種入口。經目查詢會先將簡體輸入轉為繁體。作譯者按 CBETA 相同的筆劃分組，並用 `zh-Hant` ICU Collator 排序，再依 CBETA 作譯者 ID 查詢；排序引擎僅在首次開啟作譯者頁籤時初始化。年代會顯示西元範圍與典籍數；作品列表會同時顯示 CBETA 經號。Goto 支援直接輸入行號，或貼上包含括號的 CBETA 引文（例如 `CBETA 2026.R2, B22, no. 117, p. 5a1`），並轉成 CBETA 行號格式後定位。書籤保存在裝置上，長按書籤按鈕可檢視、開啟或刪除已存位置。

選經目錄、作譯者、年代、作品清單及卷目 API 回應會在應用程序存活期間快取；關閉再開選經抽屜不會重新下載已讀取的靜態清單或目錄資料。首頁搜索框位於「關於我們」之後、「上次閱讀位置」之前；閱讀頁品牌標誌可返回首頁。閱讀頁標題區的卷選單可直接切換同一部作品的卷；未指定卷（一般作譯者/目錄選取）時預設打開第一卷，Goto 導航則仍然定位到引文指定的卷。重複的卷標題只顯示一次，但重複標題原有的行碼仍保留作為導航錨點。

首頁提供與 CBETA 手機版相近的歡迎內容、選經入口、上次閱讀位置、最近閱讀及書籤；最近提交的搜尋詞會保存在裝置上，聚焦搜尋框時以可篩選的下拉選單顯示供再次搜尋，最多保留 20 筆。搜尋結果頁點擊 CBETA 標誌或按系統返回會清除目前搜尋並回到首頁。清除最近閱讀會先要求確認，確認後刪除所有離線經卷快取及最近閱讀記錄；書籤與其他介面設定保留不變。選經器以約四分之三屏的抽屜呈現，可點擊外側關閉。各頁工具列及介面設定面板均可切換繁體／簡體顯示，文字依目標字體轉換並保留未收錄字元，設定會儲存於裝置。首頁保留「關於我們」入口，不提供切換桌面版按鈕。經文解析會保留 CBETA 標題層級，並依層級調整標題字級與粗細。

罕見字回退字型採用 CBETA 官方 `CBETASupplement` 子集，來源為 [cbeta-org/cbeta-fonts](https://github.com/cbeta-org/cbeta-fonts)，並依官方說明僅供非營利及個人研究使用；其內含字形亦受來源字型授權限制，請勿將此字型用於商業用途。此字型支援 Ext B 等擴展區字符號，例如 `𭔹`、`𥨊`。首頁標誌與應用程式圖示使用 CBETA 手機版提供的圖檔。

CBETA 搜尋服務未開放瀏覽器跨域存取，因此搜尋目前僅能在桌面或行動版 App 使用，Flutter Web 版會顯示提示訊息。

Linux 桌面版除 Flutter Linux toolchain 外，使用 ICU 原生排序時也需要與系統 Clang 版本相符的 LLVM linker 和工具集。在 Ubuntu 24.04／Clang 18 環境中可安裝：

```sh
sudo apt-get install lld-18 llvm-18
```
