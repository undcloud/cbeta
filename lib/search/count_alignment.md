## 3. 已知差异来源

### 3.1 统计口径（已确认，非缺失）

线上「笔」是作品+卷结果行，本地「部」是作品数，两者本来就不能直接比。
本地「卷」才与线上 `num_found` 同一量级。

### 3.2 夹注未进入本地索引（已确认，主要差异）

`lib/scripture/sidx_store.dart` 的 `normalizeScriptureLines()` 会把
`ScriptureLine.inlineNotes` 区间加入跳过范围（约 455 行），本地正文因此不含夹注；
线上 `total_term_hits` 会把夹注内的匹配计入。

按同一套正規化规则复制语料后估算，夹注贡献约：

- 解脫：约 3277 处
- 菩提：约 6729 处

该数字是离线模型估算，尚未逐卷与线上核对。是否把夹注纳入索引属于产品决策，
一旦纳入需要提升 `sidxNormVersion` 并重建全部 `.sidx`。

### 3.3 本地缺失或过期的经卷（已抽查，待全面复核）

以解脫为例：

- 线上有 84 个「作品+卷」结果行在本地语料中不存在，对应约 1177 处命中。
- 约 40 部作品本地没有正文，对应约 419 处命中。
- 语料版本落后：例如 T0001 本地为 202，线上当前为 214。

这三类会直接减少本地作品数、卷数与处数，需要重新下载/更新本地经卷后再取快照。

### 3.4 本地不索引的内容（已确认）

- 作译者行（`byline`）与卷首 `No. ...` 提示行。
- `lb` / `lineinfo` 行号文字。
- `#back` 校勘、注释等后置内容。

线上 `total_term_hits` 对这几类的处理并不完全等同于本地，命中差异需按词抽查。

### 3.5 正規化与正文拼接（已确认存在，方向不一）

本地会删除空白与固定标点、拼接跨行文字，并把卷题纳入索引（`sidxNormVersion = 2`），
可能比线上多算；线上按自身分段规则统计，也可能少算。

离线模型复现结果（同一语料、逐卷去掉标签后匹配）：

| 查询词 | 模型结果 | App 实际 | 差值 |
| --- | ---: | ---: | ---: |
| 解脫 | 131413 | 131440 | -27 |
| 菩提 | 190817 | 189960 | +857 |

说明模型已接近但未完全等价，做最终对齐前必须用 App 的真实索引重新取数。

## 4. 后续完全对齐的核对顺序

1. 重新下载/更新本地经卷，记录语料快照（作品数、卷数、每个 work 的版本）。
2. 用 `rows=2000&around=0` 分批取回线上全部结果行，建立「work + juan」维度的线上命中表。
3. 用同一查询跑 1.0.5 本地扫描，导出「work + juan」维度的本地命中数，与线上按行 join。
4. 把差异逐行归类：本地缺卷、语料版本落后、夹注、行号/作译者/后置内容、正規化拼接。
5. 再决定夹注是否纳入索引；若纳入需提升 `sidxNormVersion` 并重建全部 `.sidx`。
6. 重跑解脫、菩提、五蕴，把新数字补充到第 2 节，并保留旧快照作对比。
